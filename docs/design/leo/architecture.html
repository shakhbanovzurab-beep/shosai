Separated layers (ADR 0023, 0029)

  • • Application: who asks, through which channel
  • • Agent Core: what happens next in the run
  • • Decision Layer: should it happen, when, how strongly
  • • Memory & Context: what the model needs, within budget
  • • Tools & Skills: owned by domain slices, routed per turn
  • • Proactive Engine: is it worth the user's attention

Confirm-before-write (ADR 0025)

  • • One Action Gateway for every channel, MCP and errands included
  • • Frozen plan → server preview → single-winner approval
  • • Idempotent execute; crash → outcome_unknown, never retried
  • • Taint from external text: egress and voice need the screen
  • • Audit per item through the outbox, no content

Decision Layer on Jev (ADR 0026)

  • • Versioned policies; features computed in code
  • • Hard rules before and after: only more conservative
  • • Bands from calibration; shadow before promotion
  • • Fallback on timeout, error or missing consent
  • • Never decides confirmation, access or text

State and residency (ADR 0024, 0030)

  • • Conversations authoritative in the user's home DB
  • • Valkey: only active and paused runs, ≤ 24 h
  • • Memory facts with source, supersession, candidates
  • • Switches respected on every writer
  • • Decision records: ids and probabilities, no text

Context and protocol (ADR 0031, 0032)

  • • 8 segments, static first; ≈ 10–12K tokens vs ≈ 30K
  • • Tool results as digests + read_result
  • • /v1/agent/* with SSE ids and resume
  • • Native routes and reminder.* frames unchanged
