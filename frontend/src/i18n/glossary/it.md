# Glossary: Italian (it)

Address the user with informal tu (il tuo, Controlla, Carica); never Lei or voi, and the interface never speaks as «noi».
Buttons and menu items use the tu imperative in sentence case (Salva, Aggiungi attività), never the infinitive (Salvare) or a noun (Salvataggio).
Errors are «Impossibile» + infinitive, then the fix: «Impossibile salvare. Controlla la connessione.» Empty states are «Ancora nessun …» + an imperative hint: «Carica un file per iniziare.»
Loanwords (file, chat, link, token, team, account, email, hub, skill, prompt, app) never take -s in the plural; gender is in Notes. The ICU many form takes di: «# di file».
