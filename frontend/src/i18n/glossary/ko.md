# Glossary: Korean (ko)

No pronoun for the user (never 당신, 귀하); every message, error and hint is polite 해요체 (저장했어요), never 합니다체 or 반말; requests end in “…해 주세요”.
Buttons, menu items and tabs are action nouns, object first (저장, 작업 추가, 링크 복사; native verbs take -기: 만들기, 닫기), never 저장하기 or 저장하세요, no final period.
Errors: “…지 못했어요.” plus a fix when it helps (“연결을 확인해 주세요.”), never 오류!, 실패했습니다 or 죄송합니다; empty states: “아직 …이(가) 없어요.” plus a “…해 보세요.” hint.
After names and placeholders choose the particle by sound (Leo가, Studio를, Notion을); write 을(를), 이(가), (으)로 only when the word can’t be known; keep standard spacing (할 수 있어요, 저장 중).
