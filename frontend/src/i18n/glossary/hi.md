# Glossary: Hindi (hi)

Address the user as आप. Buttons are short polite commands in Google’s Hindi style: loanword + करें (सेव करें, शेयर करें) or a verb in -एं with anusvara (जोड़ें, बनाएं, never बनाएँ).
Prefer everyday Hindustani and established English loanwords written in Devanagari with nukta (फ़ाइल, फ़ोल्डर, ज़्यादा); Latin only for do-not-translate names and acronyms (URL, PDF, AI). No Sanskritized Microsoft terms (सहेजें, साझा, संलग्न).
Errors: “… नहीं किया जा सका।” agreeing with the noun, then the fix as its own sentence. Empty states: “अभी तक कोई … नहीं है” plus one how-to-start sentence. Progress: “… हो रहा है…”.
Sentences end with । (no space before it); buttons, labels and headings take none. Leo is grammatically masculine (Leo सोच रहा है…, मैं … नहीं पढ़ सकता।).
