# Glossary: Traditional Chinese (Taiwan) (zh-Hant)

Address the user as 你, never 您; calm, plain Taiwan product register (Google, Apple, Notion), no chatty particles, and generate is always 產生, never 生成.
Buttons, tabs and menu items are a bare verb or verb + object (儲存, 新增任務), never 請 and no end punctuation; sentences end in 。 with full-width ，：；？！ and 「」『』.
Errors: 無法… then the fix as a second sentence (無法儲存。請檢查網路連線。); empty states: 還沒有… then how to start (還沒有檔案。上傳檔案即可開始使用。).
Half-width space between Chinese and Latin words, numbers or placeholders (與 Leo 對話, {count} 個檔案), none next to full-width punctuation; plurals use only other, always with a measure word; the ellipsis is one …, never doubled.
