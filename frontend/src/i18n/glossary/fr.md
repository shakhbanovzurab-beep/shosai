# Glossary: French (fr)

Address the user as « vous ». Buttons and menu items use the infinitive (« Enregistrer », « Ajouter une tâche »); body text uses the vous imperative (« Vérifiez votre connexion. »). No « Veuillez », no exclamation marks.
Errors open with « Impossible de … » saying what failed, then a short fix; empty states say « Aucun … pour l’instant » plus a hint (« Importez un fichier pour commencer. »).
Sentence case everywhere, with accents on capitals (« Échéance », « À propos de vous »). Rephrase instead of writing inclusive forms such as « invité(e) » or « invité·e ».
Typography: « … » with U+202F inside, U+202F before : ; ! ?, no space before …, and ’ in every elision (« l’instant », « d’enregistrer »).
