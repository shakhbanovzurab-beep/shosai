# Glossary: Brazilian Portuguese (pt-BR)

Address the user as “você” with third-person verbs (“Verifique sua conexão”); never “tu”, “o senhor” or European Portuguese forms.
Buttons and menu items use the infinitive (“Salvar”, “Adicionar tarefa”); hints and instructions use the você imperative (“Faça upload de um arquivo para começar”).
Errors: “Não foi possível …” + what to do; never “Erro!”, “Ops” or “Falha ao…”. Empty states: “Nenhum/Nenhuma … ainda” + a hint. Confirmations stay short, without “com sucesso”.
Participles and adjectives agree in gender (Nota excluída, Link copiado); use neutral wording for people (“Boas-vindas”, not “Bem-vindo(a)”); weekdays and months in lowercase.
