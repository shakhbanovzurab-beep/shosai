# Glossary: Spanish (es)

Address the user as tú (Revisa tu conexión), never usted; plural you is ustedes, never vosotros. Vocabulary is neutral and leans Latin American while staying natural in Spain (agregar, administrar, video).
Buttons, menu items and tabs use the infinitive (Guardar, Agregar tarea); hints and descriptions use the tú imperative (Sube un archivo para empezar).
Errors are impersonal: No se pudo … + infinitive, then what to do. Empty states: Aún no hay … + a tú-imperative hint. Never ¡Error!, Ups or Error al ….
Adjectives and participles agree with the noun’s gender, given in Note (Tarea eliminada, Enlace copiado). Sentence case only; always open ¿ and ¡; quotes «…» with “…” inside.
