# Glossary: Indonesian (id)

Address the user as “Anda” (always capital A) or leave the pronoun out; plain standard Indonesian, never kamu, aku or slang, and never Malay words (fail, padam, tetapan, muat naik). Leo calls itself “saya”.
Buttons use the bare command form, or the -kan form where that is standard (Simpan, Hapus, Unggah, Tambahkan, Bagikan); no Silakan, no me- prefix on buttons. Sentences and progress text use the me- form (Menyimpan…, Mengunggah…).
Errors: “Tidak dapat” + me- verb, then the fix as a second sentence (“Tidak dapat menyimpan. Periksa koneksi Anda.”); never Gagal, Error or Ups. Empty states: “Belum ada …” + an invitation with the bare verb (“Unggah file untuk memulai.”).
Nouns never take a plural form: no reduplication in the UI (3 file, semua tugas), ICU plurals have only other. Adopted loanwords (file, folder, email, chat, template, prompt, skill) are lowercase mid-sentence.
