# Glossary: German (de)

Address the user as du in lowercase (du, dein, dich), never Sie; the interface never says ich or wir. Buttons, menu items and tabs use the infinitive (Speichern, Aufgabe hinzufügen); hints use the du-imperative (Lade eine Datei hoch, um loszulegen).
Errors are passive, name what failed, then the fix: „Datei konnte nicht gespeichert werden. Prüfe deine Verbindung.“ Empty states are Noch keine … plus a du-imperative hint. Never Fehler!, Hoppla or fehlgeschlagen.
Loanwords have a fixed gender (das Meeting, der Workspace, das Board, der Skill) and take a hyphen in compounds (MCP-Server, Pro-Tarif, Workspace-Mitglieder); keep buttons to one or two words. Quotes „…“, apostrophe ’, and … directly after the word (Wird geladen…, Umbenennen…).
Use the generic forms given here (Inhaber, Teilnehmer) or neutral wording (Person, Mitglied); no gender star, colon or Binnen-I.
