# Glossary terms (English source)

Every concept the interface names, with what it means in Studio. Each language file in this folder has one
row per term below, in the same order. Terms in the "Do not translate" list of `../GLOSSARY.md` are not here.

| Term | Area | Meaning in Studio |
| --- | --- | --- |
| Personal | navigation | The user's own space, as opposed to a workspace. Label in the space switcher |
| workspace | navigation | A shared space of a team: members, projects, meetings, decisions, knowledge |
| Hub | navigation | The section that lists hubs |
| hub | navigation | One piece of work (a deal, a project, a hire) that gathers its meetings, tasks, files and agreements |
| Productivity | navigation | The home section: today's tasks, focus timer, projects |
| Inbox | navigation | The mail section (also "Email" in the sidebar) |
| Meetings | navigation | The section with recorded and upcoming meetings |
| Calendar | navigation | The calendar section |
| Kanban | navigation | The section with task boards |
| Notes | navigation | The section with notes generated from meetings |
| File Manager | navigation | The section with the user's files |
| Knowledge | navigation | What Leo answers from: files, connected sources, workspace knowledge |
| Settings | navigation | The settings dialog |
| Support | navigation | Help and support tickets |
| Upgrade plan | navigation | Go to a paid plan |
| Download the app | navigation | Desktop and mobile apps |
| task | work | A to-do item, on a board or in a workspace |
| board | work | A Kanban board of columns |
| column | work | A stage on a board (e.g. Ideas, Planned, Shipped) |
| project | work | A group of tasks with a goal and a due date |
| decision | work | Something agreed in a meeting, tracked in a workspace |
| agreement | work | A promise someone made in a meeting ("I'll send it by Friday") |
| action item | work | A follow-up task taken from a meeting |
| due date | work | When a task must be done |
| owner | work | The person who owns a file, meeting or workspace; also the access role |
| task owner | work | The person responsible for a task or a hub topic. Not the same word as owner |
| lead | work | The person who leads a project or team: “Led by {name}” |
| assignee | work | The person a task is given to |
| priority | work | High / Medium / Low |
| status | work | The state of a task, document or payment |
| template | work | A ready-made starting point (a task, a board) |
| automation | work | A rule that acts on tasks by itself |
| meeting | meetings | A call or an in-person meeting that Studio records |
| recording | meetings | The audio or video file of a meeting |
| transcript | meetings | The text of what was said in a meeting |
| transcribing | meetings | Turning a recording into a transcript (shown while in progress) |
| summary | meetings | A short account of a meeting written by Leo |
| key points | meetings | The main points of a meeting |
| mind map | meetings | A diagram of a meeting's topics |
| participant | meetings | A person who took part in a meeting |
| file | files | Any uploaded file |
| folder | files | A container for files or notes |
| starred | files | Marked as a favourite |
| shared | files | Shared with other people |
| trash | files | Where deleted files go before removal |
| upload | files | Send a file from the device to Studio (verb and noun) |
| share link | files | A link that opens a file, note or board |
| document | knowledge | A file added to the knowledge base |
| source | knowledge | A connected service Leo reads from (Google Drive, Notion…) |
| connector | knowledge | The integration with an outside service |
| sync | knowledge | Fetching new and changed content from a source |
| index / indexing | knowledge | Preparing content so Leo can search it |
| context | studio | What Leo always knows about the user ("About you") |
| prompt | studio | Instructions for a role, written by the user |
| system message | studio | The hidden instructions sent to the model before the user's question |
| skill | studio | An installable package of instructions and tools for Leo |
| model | studio | An AI model (names like Claude are not translated) |
| role | studio | A job Leo does: live answers, code, transcript… (not a permission role) |
| temperature | studio | The model's randomness setting |
| max tokens | studio | The longest answer the model may write |
| reasoning | studio | The model thinking before it answers |
| token | studio | The unit models count text in |
| frontier models | studio | The most capable, most expensive models |
| account | settings | The user's sign-in and profile |
| profile | settings | Name, photo and work role |
| privacy | settings | Data and model-training choices |
| billing | settings | Plan, payment method, invoices |
| plan | settings | Free, Pro, Team… |
| subscription | settings | The recurring payment for a plan |
| seat | settings | One paid place for a member of a workspace |
| invoice | settings | A bill for a payment |
| payment method | settings | A card used to pay |
| usage | settings | How many tokens were used this week |
| limit | settings | The most that may be used |
| memory | settings | What Leo remembers about the user between chats |
| custom instructions | settings | How the user wants Leo to answer |
| MCP server | settings | A server that gives Leo extra tools (MCP is not translated) |
| tool | settings | One action an MCP server offers |
| member | workspace | A person in a workspace |
| team | workspace | A group of members inside a workspace |
| invitation | workspace | An invite to join a workspace |
| role (access) | workspace | What a member may do: owner, admin, member, guest |
| chat | leo | A conversation with Leo |
| message | leo | One message in a chat or a mail thread |
| new chat | leo | Start a conversation from scratch |
| voice mode | leo | Talking to Leo out loud |
| attach / attachment | leo | Add a file to a message / the file itself |
| regenerate | leo | Ask Leo to write the answer again |
| suggestions | leo | Ready-made questions to ask Leo |
| needs approval | leo | An action Leo waits for the user to allow |
| thread | mail | An email conversation |
| reply / reply all / forward | mail | Mail actions |
| draft | mail | An unsent email |
| archive | mail | Move out of the inbox without deleting (verb) |
| label | mail | A tag on an email |
| Save | actions | Keep changes |
| Cancel | actions | Close without changes |
| Done | actions | Finish an editing step |
| Create | actions | Make something new |
| Add | actions | Put something into a list |
| Edit | actions | Change something |
| Rename… | actions | Change a name (opens a dialog) |
| Duplicate | actions | Make a copy |
| Delete | actions | Remove for good |
| Remove | actions | Take out of a list without destroying it |
| Restore | actions | Bring back from the archive or trash |
| Undo | actions | Reverse the last action (in a toast) |
| Retry / Try again | actions | Repeat what failed |
| Close | actions | Close a dialog or panel |
| Copy link | actions | Put a link on the clipboard |
| Search | actions | Find |
| Filter | actions | Show only matching items |
| Sort | actions | Change the order |
| Connect / Disconnect | actions | Link or unlink an outside service |
| Log out | actions | Sign out of Studio |
| Manage | actions | Open the controls for something |
| Couldn’t … | patterns | Error message pattern: "Couldn’t save", "Couldn’t load the files" |
| No … yet | patterns | Empty-state pattern: "No files yet" |
| Saving… / Loading… | patterns | Progress, with the ellipsis character |
| … copied | patterns | Confirmation toast: "Link copied" |
