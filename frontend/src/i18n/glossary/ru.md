# Glossary: Russian (ru)

Address the user as «вы» (lowercase). Plain and friendly: no officialese («данный», «осуществить») and no anglicisms where a Russian word exists.
Buttons and menu items take the perfective infinitive («Сохранить», «Добавить задачу»), with «Отмена» as the usual exception. Hints use the вы-imperative («Загрузите файл»).
Errors are «Не удалось …» plus the fix. Empty states are «Файлов пока нет». Toasts use a short participle that agrees with the noun («Файл удалён»).
Leo is masculine and never declined («Leo не смог ответить», «Спросите Leo»). Keep ё where this file has it (ещё, всё, договорённость, счёт).
